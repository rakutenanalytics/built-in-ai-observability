Tool call testing

Click Tool call to run a multi-round exchange. Needs chrome://flags/#prompt-api-tool-use and a browser restart. One trace records several generate_content spans plus an execute_tool span per call.

Available tools (cities: Tokyo, Kyoto, Osaka only):

  • get_weather— current conditions and temperature
  • get_population— population for a city

Ask a question that needs one or both tools, then click Tool call. An empty prompt uses the Kyoto example below.
